Chamaeleo convexus

cvx switches your Convex account as you cd into each project, and every terminal keeps its own.

Can you spot her? She hides on one of four accounts.

brew install rafay99-epic/apps/cvx

ISpecimen

Other mascots watch your cursor. Vex watches your working directory. Each field mark is a feature.

IIHabitat

Your projects are twigs on one branch. Wherever she grips, she takes that folder's account. On an unlinked twig she asks which one.

← drag me →
  1. ~/code/webpersonal
  2. ~/code/billingwork
  3. ~/clients/atlasclient
  4. ~/scratchnot linked

cd ~/code/web → personal. This terminal now exports its own token.

IIIColony

One Vex per terminal, each on her own branch, all at once. Without cvx they share one global login. Tap the glass and each looks for herself.

  • tty1 personal ✓

  • tty2 work ✓

  • tty3 client ✓

  • tty4 acme ✓

With cvx: every terminal holds its own account, at the same time. Each tail is its own session token.

IVMoods, observed

Six moods, each one a real line from the CLI. Hover or focus a specimen to read it.

  1. happy09:02, after cd into billing

    ⇄ convex account → work

  2. wink09:40, doctor finds nothing wrong

    Everything looks good. ~ Vex approves (◕‿<)~@ ~

  3. curious10:15, an unlinked folder

    This directory isn't linked to an account.

  4. alarm11:03, deployment owned by another team

    ▲ team mismatch: this project's deployment belongs to acme-labs

  5. sleepy13:30, the vault is locked

    ⚿ vault locked: run cvx vault unlock to switch to work

  6. sad17:55, an account removed

    ✓ Removed account work · cvx undo restores it

A note on the casque. The default file vault keeps tokens in plaintext, readable only by you (mode 600). For encryption, use the OS keychain (cvx keychain enable) or the passphrase vault (cvx vault encrypt).
